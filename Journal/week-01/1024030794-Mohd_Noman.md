# Week 1 — P4: Frontend / Dashboard

## Objective

Scaffold the React + TypeScript dashboard project, define the shared data-contract types on the frontend side, and get a first render working against hand-written mock data shaped like the future backend output.

## Work Completed

- Scaffolded the project with Vite (`react-ts` template).
- Set up the folder structure: `types/`, `data/`, `components/`.
- Defined TypeScript interfaces for `NexoraEvent` and `Incident`, matching the team's Week 1 data contract (event schema + incident schema).
- Wrote hand-written mock data (`mockData.ts`) modeling a realistic attack chain: auth failure burst → auth success (new context) → privileged DB access → large data transfer — matching the credential-stuffing pattern described in the project proposal.
- Built the `LiveFeed` component fully — renders event type, user, IP, timestamp, and severity (color-coded) from mock data.
- Scaffolded `AnomalyChart`, `IncidentTimeline`, and `EvidencePanel` as stub components with clear `TODO(Week N)` markers for their real implementation.
- Assembled all four components into a single `App.tsx` dashboard layout.
- Added baseline layout/styling so all panels render legibly in a 2x2 grid.
- Verified type-checking and production build both succeed with no errors.

## Files Added

## Validation

Ran `npm run dev` and confirmed all four dashboard panels render correctly against mock data: live feed shows 5 chronologically ordered events with correct severity coloring, incident timeline shows the reconstructed `credential_stuffing_chain` incident with linked event count, and the evidence panel shows confidence score, entities, and recommended action pulled from the mock incident object.

## Key Concepts Learned

- Vite + React + TypeScript project scaffolding
- Structuring a frontend around a shared data contract (schema-first development)
- TypeScript interfaces for cross-team API contracts
- Component composition for a multi-panel dashboard layout

## Current Limitations

- `AnomalyChart`, `IncidentTimeline`, and `EvidencePanel` are functional stubs only — no charting (Recharts) or graph visualization (react-flow) yet.
- Styling is placeholder/functional only; a real design pass is planned for the UI polish week.
- No live data connection yet — everything currently reads from static mock data, not a WebSocket or API.
